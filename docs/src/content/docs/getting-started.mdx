Install `@samline/counter`, then follow the Package / ESM or the HTML / CDN path to the first counter. Both use the same API.

## Requirements

- Any modern browser with `Intl.NumberFormat`. Without IntersectionObserver, numbers count right away.
- On the server, `counter` and `autoCounter` return no-ops and `animateNumber` jumps to the end.
- No runtime dependencies.

## Package / ESM

```js
import { autoCounter } from '@samline/counter'

autoCounter()
```

```html
<p lang="en">
  <span data-counter="12480">12,480</span> customers · <span data-counter="99.95">99.95</span>%
  uptime
</p>
```

`autoCounter()` counts every `[data-counter]` in the page, including numbers added later. To count specific elements, call `counter(target, options)`; both return a way to stop. Available as ESM and CommonJS (`require('@samline/counter')`). There is no stylesheet.

## HTML / CDN

For Shopify, WordPress or plain HTML pages without a build step, load the browser bundle. It counts every `[data-counter]` as soon as the DOM is ready. Pin the version in production.

```html
<script
  src="https://cdn.jsdelivr.net/npm/@samline/counter@1.11.0/dist/browser/counter.global.js"
  defer
></script>
```

To pass options, add `data-manual` to the script tag and start it yourself, or call `Counter.auto()` from a script that runs before the DOM is ready (a deferred or inline script after the bundle):

```html
<script
  src="https://cdn.jsdelivr.net/npm/@samline/counter@1.11.0/dist/browser/counter.global.js"
  data-manual
  defer
></script>
<script type="module">
  Counter.auto({ duration: 1500, locale: 'es-MX' })
</script>
```

## Lite build

Since 1.8.0, `@samline/counter/lite` counts plain numbers with everything a stats band needs: formatting and the text template, easings, speed, stagger, live values, the controller and the label for screen readers. It leaves out clocks and dates (`data-counter-as="time"` and `"date"` stay as rendered), `cssVars`, `output`, `steady`, `roll`, `scramble` and `announce`, counts `start: 'scroll'` once on visibility, and weighs about 7 KB gzip instead of 10 KB. The API and the attributes are the same, so you can switch either way.

```js
import { autoCounter } from '@samline/counter/lite'

autoCounter()
```

```html
<script
  src="https://cdn.jsdelivr.net/npm/@samline/counter@1.11.0/dist/browser/counter-lite.global.js"
  defer
></script>
```

The lite script also defines `window.Counter`, so load one of the two bundles, not both.
